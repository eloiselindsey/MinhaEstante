MINHAESTANTE - Biblioteca Pessoal
Projeto acadêmico AV2

--------------------------------------------------
COMO RODAR NO XAMPP
--------------------------------------------------

1) Abra o XAMPP Control Panel e clique em "Start" no APACHE e no MYSQL.

2) Copie a pasta "minhaestante" inteira para dentro de:
   C:\xampp\htdocs\

   O caminho final deve ficar assim:
   C:\xampp\htdocs\minhaestante\index.html

3) Crie o banco de dados:
   - Acesse http://localhost/phpmyadmin
   - Clique na aba "SQL"
   - Abra o arquivo banco.sql, copie todo o conteúdo e cole na caixa
   - Clique em "Executar"

4) Abra o site no navegador:
   http://localhost/minhaestante/index.html

IMPORTANTE: sempre abra pelo endereço "localhost".
Se você der dois cliques no index.html direto na pasta, os links
para as páginas .php NAO vao funcionar.

--------------------------------------------------
ESTRUTURA DOS ARQUIVOS
--------------------------------------------------

minhaestante/
  index.html        -> pagina inicial
  sobre.html        -> sobre o projeto
  contato.html      -> formulario com validacao em JavaScript
  livros.php        -> LISTAR os livros (Read)
  cadastrar.php     -> CADASTRAR livro (Create)
  editar.php        -> EDITAR livro (Update)
  excluir.php       -> EXCLUIR livro (Delete)
  conexao.php       -> conexao com o banco MySQL
  banco.sql         -> script para criar o banco e a tabela
  css/style.css     -> estilos (flexbox + responsivo)
  js/script.js      -> validacao do formulario de contato
  img/              -> pasta para imagens (coloque aqui a logo, se quiser)

--------------------------------------------------
POSSIVEIS ERROS
--------------------------------------------------

"Erro ao conectar no banco de dados"
  -> O MySQL nao esta ligado no XAMPP, ou voce ainda nao rodou o banco.sql.

Aparece o codigo PHP na tela em vez do site
  -> Voce abriu o arquivo direto da pasta. Use http://localhost/minhaestante/

Acentos aparecem estranhos
  -> Confira se o banco foi criado com utf8mb4 (ja esta no banco.sql).
